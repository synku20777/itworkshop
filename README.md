# IT-Workshoppen

A static website for IT courses and workshops.

## Local development

Install [Node.js](https://nodejs.org/) if it is not already available. From the project directory, run:

```sh
npm run dev
```

Open http://localhost:3000. Edit the HTML, CSS, or JavaScript and refresh the browser to see changes. Press `Ctrl+C` in the terminal to stop the server. No package installation is required.

To use a different port in PowerShell, run `$env:PORT=4000; npm run dev`. On macOS or Linux, run `PORT=4000 npm run dev`.
